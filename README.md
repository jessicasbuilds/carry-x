# Carry X

**Autonomous Follow-Me Robotic Platform**

Carry X is a robotics concept focused on creating a mobile platform that can follow a user and transport belongings.

## System Focus

- Autonomous user-following
- Mobile locomotion and motor control
- Sensors and environmental awareness
- Human-machine interaction
- Electromechanical system integration
- Control logic and safety considerations

## Engineering Approach

The project is structured as a full system rather than a single mechanism: mobility, sensing, controls, power, mechanical packaging, and user interaction all have to work together.

## Current Scope

This repository documents the concept, system architecture, and engineering direction. It does not claim a completed autonomous production prototype.
